# NLP Sentiment Analysis Dashboard

An interactive NLP project built using Python.

## Features
- Sentiment Analysis
- Text Cleaning
- Tokenization
- Stopword Removal
- Stemming
- Lemmatization
- Word Frequency Analysis
- Interactive Gradio Dashboard

## Technologies
- Python
- Gradio
- TextBlob
- NLTK
- Pandas

## Platform
Google Colab
